Generador de códigos de barras

Crea el código de barras de tus productos, descárgalo como imagen o imprímelo para pegarlo. Funciona con cualquier lector de códigos.

¿Qué tipo de código uso?

EAN-13 es el estándar de los productos de supermercado: 12 números más un dígito de control que se calcula solo. Code 128 admite letras y números y es útil para códigos internos de tu tienda.

Los códigos que generes aquí sirven para tu inventario interno. Para vender productos con código propio en cadenas de supermercados necesitas códigos asignados por GS1 Venezuela.

Preguntas frecuentes

¿Funciona con mi lector de códigos?

Sí. Cualquier lector USB, Bluetooth o la cámara del móvil leen EAN-13 y Code 128.

¿Puedo hacer etiquetas para todo mi inventario?

StockSoft crea e imprime etiquetas en hoja A4 o en impresora térmica para todos tus productos a la vez, con el precio en $ y Bs.
