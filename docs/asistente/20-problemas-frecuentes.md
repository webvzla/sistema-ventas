# Problemas frecuentes y soluciones

| Problema | Causa probable | Qué hacer |
|---|---|---|
| «Correo o contraseña incorrectos» | Datos mal escritos | Revisa mayúsculas; usa **¿Olvidaste tu contraseña?**. Empleado con PIN: escribe su **usuario** (ej. maria-4821) en «Correo o usuario». |
| «Esta cuenta no pertenece a ningún negocio» | El usuario fue eliminado o nunca se añadió | El administrador debe crearlo en **Más → Usuarios**. |
| «La prueba gratis terminó» / «La licencia venció» | Fin del periodo | El administrador entra y escribe un **código de activación** (los datos siguen guardados). |
| «El acceso de este negocio está suspendido» | Bloqueo de StockSoft | Contactar con soporte. |
| «No tienes permiso para hacer eso» | Acción reservada al administrador | Entrar como administrador. |
| «Sin internet» | Sin conexión | Puedes seguir vendiendo; se sincroniza al volver. |
| No veo los Bs / «Pon la tasa para ver Bs» (Venezuela) | No hay tasa guardada | **Tasas del día → Buscar la tasa del BCV ahora** o ponerla a mano. |
| La caja no cuadra | Formas de pago mal elegidas, gastos en efectivo | Revisa las ventas y corrige con **Cambiar forma de pago**. |
| «Para la factura pon …» / número fiscal no válido | Falta o está mal el NIF/RIF/RFC del cliente | Escribe el número real; si el cliente no lo da, usa **Factura simplificada** o **Venta sin documento** (fuera de Venezuela). |
| «El importe supera 400 €» (España) | Aviso orientativo | Valora hacer **Factura completa** y consulta a tu asesor. |
| El precio final no es el que esperaba | Modalidad de precios «No incluyen impuestos» | Revisa **Ajustes → Impuestos → Precios de venta**. |
| «Ojo: … figura agotado» | Stock en cero | Repón stock o revisa el conteo. |
| «Este producto está en euros: falta la tasa del euro» (Venezuela) | No hay tasa del euro | Pon la tasa del euro en Tasas del día. |
| La importación de Excel no encuentra columnas | Títulos poco claros | En «Así entendí tu archivo» elige la columna correcta o usa la plantilla. |
| Me equivoqué al importar | — | **Deshacer última importación** (mismo navegador o PC). |
| «Demasiadas operaciones seguidas, espera un momento» | Muchas escrituras en poco tiempo | Esperar unos segundos y repetir. |
| No llega el correo de confirmación o de contraseña | Filtro de spam | Revisa spam o promociones. |
