Por qué usar códigos de barras

Buscar un producto por nombre en la caja tarda segundos y se presta a errores ("¿era la harina de 1 kg o la de 500 g?"). Con el código de barras el producto exacto aparece al instante, con su precio actualizado. Además, el inventario se descuenta del artículo correcto, lo que hace que tus conteos cuadren.

No necesitas un lector caro para empezar: muchos programas de ventas leen códigos con la cámara del teléfono, y un lector USB básico funciona como un teclado que "escribe" el código.

EAN-13: el código de los productos

Casi todos los productos de consumo traen un código EAN-13: 13 dígitos que identifican al fabricante y al producto. Los primeros dígitos indican el organismo que asignó el código (los productos registrados en Venezuela suelen empezar por 759), luego vienen el fabricante y el artículo, y el último es el dígito de control.

Ese código lo pone el fabricante y es el mismo en todos los comercios. Tú no tienes que inventarlo: solo registrarlo una vez en tu inventario escaneando el empaque.

Cómo se calcula el dígito de control

El dígito de control permite al lector detectar si un código se leyó mal. Para un EAN-13 se calcula así con los 12 primeros dígitos:

  1. Suma los dígitos en posición impar (1.º, 3.º, 5.º…).
  2. Suma los dígitos en posición par (2.º, 4.º, 6.º…) y multiplica el resultado por 3.
  3. Suma los dos resultados.
  4. El dígito de control es lo que falta para llegar a la siguiente decena (si la suma ya es decena, es 0).
Ejemplo con 759123456789

Impares: 7 + 9 + 2 + 4 + 6 + 8 = 36. Pares: 5 + 1 + 3 + 5 + 7 + 9 = 30 → × 3 = 90.

36 + 90 = 126. Para llegar a 130 faltan 4 → código completo: 7591234567894.

Códigos internos para granel y charcutería

Los productos que vendes sueltos (granos, queso, embutidos, productos que fraccionas) no traen código. Para ellos tienes dos opciones:

  • Code 128 con un código propio (por ejemplo, QUESO-BLANCO o INT-0005). Admite letras y números, ideal para uso interno.
  • EAN-13 interno empezando por 2 (rango reservado para uso interno de las tiendas), si tu sistema o tu balanza trabajan solo con números.

Lo importante es que el código interno no coincida con el de ningún producto real y que esté registrado en tu inventario.

Imprimir etiquetas que se lean bien

  • Imprime en negro sobre blanco; evita fondos de color y tinta gastada.
  • Respeta los márgenes blancos a los lados del código: sin ellos el lector falla.
  • No lo hagas demasiado pequeño: unos 3 cm de ancho son un buen mínimo para un EAN-13.
  • Pon el precio y el nombre en la misma etiqueta para el estante.
  • Prueba una etiqueta con tu lector o tu teléfono antes de imprimir cien.

Preguntas frecuentes

¿Necesito comprar códigos para mis productos?

Solo si fabricas o empacas productos con tu marca para venderlos en otros comercios; en ese caso se tramitan ante el organismo GS1 del país. Para uso dentro de tu tienda, los códigos internos son suficientes.

¿Qué hago si dos productos tienen el mismo código?

No debería pasar con EAN-13 reales. Si ocurre, suele ser un código interno repetido o un error al registrar: corrígelo en tu inventario, porque si no, se descontará el producto equivocado.
